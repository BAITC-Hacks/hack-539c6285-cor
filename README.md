# Qyran — жестовый язык для окна госуслуг

**Команда:** COR · **GovTech Camp 2026**
**Живое демо:** <https://qyran-web.vercel.app> — открывается в браузере, ничего устанавливать не нужно.

> **In short (EN).** Qyran lets a hearing clerk at a public service centre (ЦОН) and a deaf citizen understand each
> other. The clerk taps a ready phrase — the 3D avatar Elnar signs it in Russian Sign Language, with the phrase in large
> print; the citizen answers with large buttons or text, which the clerk sees and hears. Every sign in the verified
> library is built from a native signer's recording (SpreadTheSign) and checked against it frame by frame. Everything
> runs in the browser. Model weights and 3D avatars are intentionally not included in this repository.

## 1. Проблема

Глухой человек не может самостоятельно решить бытовое дело в ЦОНе, поликлинике или банке. Государство оплачивает
**60 часов сурдоперевода в год** — это около десяти минут в день, и записываться надо заранее. Всё остальное время
человек пишет в заметках телефона (а письменный русский или казахский для многих глухих — второй язык, не родной) или
приводит с собой родственника, и тогда о его делах узнаёт вся семья.

Вторая половина проблемы обычно остаётся незамеченной: **сотрудник по ту сторону стойки тоже не может ответить**. У
оператора нет способа показать «подождите», «повторите», «документ будет готов завтра». Субтитры в одну сторону эту
половину не закрывают.

**Для кого:** глухие и слабослышащие граждане; операторы ЦОНов и других окон госуслуг; их руководители, которым нужно
обслуживать всех без очереди к сурдопереводчику.

## 2. Решение: «Окно ЦОН»

Экран для окна госуслуг: `/?view=tson` (кнопка «Окно ЦОН» на главной). Работает на ноутбуке или планшете у окна, в
обычном браузере, без входа и без камеры.

```
┌────────────────────────────┬──────────────────────────────────────────────┐
│  3D-аватар Елнар           │ 1  Оператор                                  │
│  показывает фразу на       │    Приём · Очередь и ожидание · Понимание ·  │
│  русском жестовом языке    │    Сроки · Прощание — готовые фразы          │
│                            │    + своя фраза текстом                      │
│  «Пожалуйста, подождите»   │ 2  Ответ гражданина                          │
│  — крупно, для гражданина  │    Да · Нет · Не понимаю · Повторите …       │
│                            │    + свой текст → крупно и голосом           │
│  скорость 0.5× / 0.75× / 1×│ 3  Ход диалога                               │
└────────────────────────────┴──────────────────────────────────────────────┘
```

* **Оператор** нажимает готовую фразу — Елнар показывает её жестами, фраза выводится крупным шрифтом. Колода — 18 кнопок
  (`src/lib/tsonDeck.ts`): «Здравствуйте, вам помочь?», «Чем я могу вам помочь?», «Как вас зовут?», «Пожалуйста,
  подождите», «Извините», «Документ», «Да», «Нет», «Хорошо», «Пожалуйста», «Я не понимаю», «Пожалуйста, повторите»,
  «Где?», «Мы работаем сегодня», «Сегодня», «Завтра», «Спасибо», «До свидания». Можно повторить жест и замедлить его.
* **Своя фраза оператора.** Текст по-русски разбирается так: сначала целые проверенные фразы, потом отдельные слова;
  служебные слова («в», «на», «и»…) пропускаются. Если для слова жеста ещё нет, экран не подменяет его чем попало, а
  прямо пишет: «Пока нет жеста: паспорт».
* **Гражданин** отвечает крупными кнопками («Да», «Нет», «Не понимаю», «Повторите, пожалуйста», «Медленнее,
  пожалуйста», «Напишите, пожалуйста», «Спасибо») или текстом. Оператор видит ответ крупно и слышит его голосом
  (озвучку можно выключить).
* **Ход диалога** — лента последних реплик обеих сторон.
* Интерфейс на **казахском, русском и английском**. Жесты — русский жестовый язык (РЖЯ) по записям SpreadTheSign;
  сверка с тем, как показывают глухие в Казахстане, — следующий шаг (раздел 13).
* Экран показывает **только проверенные жесты** (раздел 4). Жест, который ещё ждёт проверки командой, отмечен
  пунктирной рамкой.

**Сценарий показа за две минуты:** открыть `/?view=tson` → «Здравствуйте, вам помочь?» → «Документ» → «Пожалуйста,
подождите» → в поле «Своя фраза» написать `Мы работаем завтра` → у гражданина нажать «Повторите, пожалуйста» → оператор
отвечает «Пожалуйста, повторите» → переключить язык на KZ.

## 3. Все части продукта

| экран | адрес | что делает |
|---|---|---|
| Окно ЦОН | `/?view=tson` | оператор ↔ глухой гражданин (раздел 2), публичный |
| Переводчик | «Речь → жест» на главной (после входа) | текст или речь → жесты аватара |
| Распознаватель | «Жест → речь» на главной (после входа) | камера → слово → текст и голос (раздел 5) |
| Словарь | `/?view=dictionary` | поиск слова → аватар показывает жест, публичный |
| ASL-лаборатория | `/?view=asl` | экспериментальный стенд дактиля ASL, публичный |
| Студия | только для команды | запись новых жестов в базу |

**Переводчик.** Фраза сначала ищется целиком среди проверенных фраз (в жестовом языке фраза — не сумма слов:
«Чем я могу вам помочь?» носители показывают одним знаком ПОМОЧЬ с вопросом на лице). Остальное переводится в
жестовый порядок слов (`src/lib/glossing.ts`: `Я вчера ходил в магазин с мамой` → `ВЧЕРА Я ХОДИЛ МАГАЗИН МАМОЙ`) и
показывается по словам: сначала из проверенной библиотеки, затем — из прежних источников (966 анимаций,
ретаргетированных из датасета SLOVO, процедурный словарь, дактиль). Прежние источники командой не проверены и в
интерфейсе вынесены в отдельную панель «Непроверенные жесты».

## 4. Как строятся проверенные жесты

Главное, что отличает Qyran: жест аватара **не придуман и не «примерно похож»**, а построен по записи живого носителя
РЖЯ и сверен с ней по числам и глазами.

1. **Эталон.** Для каждой фразы или слова берётся **одна** запись носителя из словаря SpreadTheSign (русский,
   Россия) — фраза целиком одним человеком, без склейки разных людей. Номер записи указан у каждого жеста в
   `src/lib/verifiedSigns.ts` и `scripts/lib/phraseRefs.mjs`.
2. **Разметка.** В браузере на странице источника MediaPipe Pose и HandLandmarker снимают каждый кадр (25 в секунду):
   запястья, локти, направление пясти, указательного и большого пальца, ориентацию ладони. Всё — в ширинах плеч от
   середины плеч носителя, поэтому не зависит от роста и камеры (`scripts/sts-analysis.browser.js`). Видео не
   скачиваются.
3. **Ключевые позы.** В `scripts/author-phrases.mjs` для каждого момента знака задаются положение запястья, форма и
   ориентация кисти; руку ставит обратная кинематика (`scripts/lib/armIK.mjs`, `scripts/lib/signKit.mjs`) на скелете
   аватара Елнара. Локоть подбирается так, чтобы в кадре встать как у носителя. Касания лица и груди считаются по
   сетке самого аватара — 3 мм «кожа к коже», без проникновения. Время — в темпе носителя: время жеста = время
   записи − T0.
4. **Автоматическая сверка** (`scripts/check-phrases.mjs`) в каждой фазе знака:
   * запястье — не дальше **0.10 ширины плеч** от носителя;
   * пясть, указательный и большой палец — в пределах **25°** от носителя (в среднем по фазе);
   * у лица и груди — касание 0…8 мм;
   * техника: старт и финиш в позе покоя, кисть не входит в лицо и корпус, интерполяция без скачков;
   * кисти двух рук нигде не проходят друг сквозь друга — по всему жесту, 60 раз в секунду (порог −3 мм кожа к коже).
   Фаза без эталонных рядов считается ошибкой, а не «прошла»: сверка не может пройти вхолостую.
5. **Сверка глазами.** `gesture-compare.html` показывает запись носителя и Елнара рядом, кадр в кадр, с калибровкой
   кадра под каждое видео (`u`, `v`, `fw` — где у носителя плечи в кадре).
6. **Последнее слово — за командой.** Жест попадает в библиотеку после сверки, а «одобренным» становится после
   проверки командой по той же записи. Одобрены 9: «Привет», «Спасибо», «Как дела?», «Как я могу помочь?», «Я люблю
   маму», «Я хочу есть», «Кто там?», «Мы работаем сегодня», «Ты идёшь в школу завтра». Остальные ждут проверки и в
   интерфейсе отмечены пунктиром (`AUDITED_FILES` в `src/lib/verifiedSigns.ts`).

**Сейчас в библиотеке:** 19 фраз и 41 слово (часть слов вырезана из фраз — из покоя в покой, тем же движением, что во
фразе). Все 59 файлов анимаций проходят автоматическую сверку.

Для «Окна ЦОН» по записям SpreadTheSign построены «Здравствуйте, вам помочь?», «Пожалуйста, подождите», «Пожалуйста,
повторите», «Извините» и слово «документ». Следующие в очереди (записи уже найдены): «Сейчас твоя очередь», «Ваш личный
номер?», «паспорт», «готово», «подпись», «платить», «окно», «очередь».

### Технический аудит всех анимаций

`scripts/audit-gestures.mjs` проигрывает каждый файл так же, как плеер сайта, и ищет физически невозможное: кисть в лице
или в корпусе, кисти сквозь друг друга, локоть за спиной, рывки. Итог на 1031 файле (15 отсчётов в секунду):

| источник | файлов | с физической ошибкой | главное |
|---|---|---|---|
| проверенная библиотека | 60 | 0 по лицу, корпусу, рукам и локтю | аудит нашёл 7 жестов, где кисти проходили друг сквозь друга на переходах между касаниями, — исправлено, проверка добавлена в сверку |
| прежние ручные файлы | 6 | 5 | локоть за спиной, кисти сквозь друг друга, «щелчки» пальцев |
| клипы SLOVO | 965 | 384 (40 %) | кисть в корпусе — 296, кисти сквозь друг друга — 106, кисть в голове — 19 |

Поэтому «Окно ЦОН» показывает только проверенную библиотеку, а прежние источники в переводчике вынесены в отдельную панель
«Непроверенные жесты». Правильность самого знака у прежних источников не проверена — эталонных записей к ним нет.

## 5. Распознавание жестов с камеры (ML) и честные цифры

Конвейер целиком работает **на устройстве**: кадры камеры не покидают браузер, сервера в контуре разговора нет. Он
повторяет тестовый стенд, на котором модель проверяли до публикации:

1. **MediaPipe Holistic** (сборка 0.5; лицо с уточнением губ и зрачков, собственное сглаживание выключено) снимает
   точки тела, рук и лица. В модель идут 85 точек: поза, 10 точек лица и обе кисти.
2. Кадр переводится в **319-мерный вектор**: координаты — в систему тела, кисть нормируется на длину ладони отдельно от
   позы, добавляются относительные расстояния и скорости (`ml/features.py`, побитовое зеркало на TypeScript —
   `src/lib/features.ts`).
3. Последние 60 кадров раз в 15 кадров классифицирует модель **Conv1D + BiLSTM** через **TensorFlow.js** — ансамбль из
   трёх сетей, их вероятности усредняются.
4. Слово принимается, если оно на первом месте с вероятностью не ниже 25 % и в 1.8 раза выше второго места два замера
   подряд. Тогда оно встаёт во фразу и озвучивается.

Браузерный MediaPipe и Python-версия, на которой собирали данные для обучения, дают на одних и тех же кадрах почти
одинаковые точки (замер на 300 кадрах: кисти расходятся на 1–2 пикселя, руки не путаются). Точность ограничивает не
трекер, а данные.

На сайте одна модель — **Qyran-240**. SLOVO-1001 с сайта убрана; её цифры оставлены как ориентир того, что даёт та же
архитектура на большом открытом датасете. Цифры — из `model_config.json` самих моделей и скриптов оценки в `ml/`:

| модель | классов | данные | top-1 на людях, которых модель не видела |
|---|---|---|---|
| **Qyran-240 — на сайте** | 240 | свой корпус: 4 066 клипов РЖЯ с YouTube | **10.2%** на 1 201 коротком клипе (5 фолдов); случайное угадывание — 0.4% |
| SLOVO-1001 — ориентир, не на сайте | 1001 | датасет SLOVO (20 400 клипов, 194 человека) | **59%** на 1 652 клипах 82 человек; top-5 — 87% |
| SLOVO-1001, словарь площадки | 208 | то же | **80.6%** (`ml/vocab_experiment.py`) |

Как читать эти цифры честно:

* официальный сплит SLOVO **не разделяет людей**: 92 из 194 человек есть и в обучении, и в тесте, поэтому главная
  метрика считается только на людях, которых модель не видела (на официальном сплите top-1 — 61.4%);
* ограничение словарём конкретного окна (две сотни знаков вместо тысячи) поднимает точность без переобучения — поэтому
  продукт строится под площадку, а не «под любые сферы»;
* Qyran-240 пока слабая: 4 066 клипов из интернета — мало. Узкое место — данные, а не архитектура: при равном числе
  клипов знаки, показанные ≥ 14 разными людьми, распознаются на 83.8%, показанные ≤ 7 людьми — на 59.0%. Собирать
  нужно разных людей, а не больше дублей;
* распознаются **отдельные знаки**, а не связная речь.

Код обучения и оценки — в `ml/` (Python, TensorFlow/Keras). Веса и файлы моделей в репозиторий не входят (раздел 6).

## 6. Что не входит в репозиторий

По решению команды здесь **нет весов и файлов ИИ-моделей и нет 3D-аватаров**. Живое демо на
<https://qyran-web.vercel.app> работает со всеми файлами.

| чего нет | где лежит в рабочей версии | без него |
|---|---|---|
| модели распознавания: Qyran-240 (ансамбль из 3), ASL-дактиль — `model.json` и веса `*.bin` | `public/model/qyran240/`, `public/model/asl_dactyl/` | распознаватель и ASL-лаборатория не запускаются |
| 3D-аватары: Елнар, Адам, Ева | `public/avatar_elnar.glb`, `public/avatar.glb`, `public/avatar_eva.glb` | сцена открывается без аватара; скрипты построения жестов (`scripts/author-phrases.mjs`, `scripts/check-phrases.mjs`) не запускаются |

Всё остальное — код, анимации жестов (`public/gestures/`), эталонные числа разметки, скрипты построения и сверки,
конвейер обучения — в репозитории. Эти правила записаны в `.gitignore`, чтобы веса и аватары не попали сюда случайно.

## 8. Запуск

Нужен Node.js 20+.

```bash
git clone https://github.com/BAITC-Hacks/hack-539c6285-cor.git
cd hack-539c6285-cor
npm install --legacy-peer-deps
npm run dev
```

Откроется на <http://localhost:5173> (если порт занят, Vite покажет другой).

```text
http://localhost:5173/?view=tson          окно ЦОН
http://localhost:5173/?view=dictionary    словарь
http://localhost:5173/?view=translator    переводчик (в режиме разработки — без входа)
http://localhost:5173/?view=recognizer    распознаватель (в режиме разработки — без входа)
```

Чтобы в локальной копии появились аватар и распознаватель, положите файлы из раздела 6 по указанным путям.

Сборка:

```bash
npm run build
```

## 9. Проверки

Без камеры, на настоящем скелете аватара (нужен `public/avatar_elnar.glb`):

```bash
node scripts/check-phrases.mjs              # все проверенные жесты против записей носителей
node scripts/check-phrases.mjs --only pozhaluysta-podozhdite   # один жест
node scripts/author-phrases.mjs pozhaluysta-podozhdite         # пересобрать один жест из ключей
node scripts/audit-gestures.mjs --out audit/                    # технический аудит всех анимаций
```

Остальные проверки в `scripts/`: `check-glossing.mjs` (фраза → жестовый порядок), `check-hand-orientation.mjs`,
`check-arm-placement.mjs`, `check-stance.mjs`, `check-feature-parity.mjs` (признаки TypeScript = Python).

## 11. Данные и приватность

* Окно ЦОН **не использует камеру**; текст оператора и ответы гражданина не сохраняются и никуда не отправляются.
  Жесты — статичные файлы анимаций с сайта, озвучка — встроенный синтез речи браузера (Web Speech API).
* Распознаватель работает **на устройстве**: кадры камеры и точки тела не покидают браузер.
* Платных API и серверных ключей в проекте нет. В `src/lib/supabase.ts` лежит только публичный ключ Supabase (роль
  `anon`) — он и должен быть во фронтенде; доступ к данным ограничен политиками RLS (`supabase/migrations/`).
* Для пилота в госоргане отдельно понадобятся хранение данных в Казахстане и согласие на запись для корпуса — это
  записано в `ROADMAP.md`.

## 12. Честные ограничения

* Это **не замена сурдопереводчику**, а инструмент для быстрых типовых дел у окна.
* Проверенная библиотека пока небольшая: 19 фраз и 41 слово. В «Окне ЦОН» слово без жеста честно называется; в
  переводчике оно пока показывается прежними непроверенными источниками, у которых технический аудит нашёл физические
  ошибки в 40 % клипов SLOVO.
* 9 жестов одобрены командой, остальные прошли автоматическую сверку и ждут проверки глазами.
* У аватара Елнара лицо относительно кисти уже, чем у людей: в жестах у лица это заметно (например, ПИТЬ).
* Мимика пока ограничена губами и поворотами головы; вопрос и отрицание лицом показываются не везде.
* Распознавание с камеры — отдельные знаки; своя модель Qyran-240 пока угадывает около 10 % коротких клипов незнакомых
  людей. Главный рычаг — свой корпус от многих разных людей.

## 13. Что дальше

1. **Колода ЦОН на 30–40 фраз** по записям носителей: «Сейчас ваша очередь», «Документ готов», «Покажите удостоверение»,
   «Распишитесь здесь», «Оплата», «Ваш личный номер?».
2. **Проверка каждой фразы носителем языка** из сообщества глухих — и только потом пилот.
3. **Пилот в одном окне ЦОН** с измеренным потоком глухих посетителей; распознаватель — с подтверждением тапом из
   топ-5 (внутри словаря площадки топ-5 — 95.6%).
4. **Мимика** (вопрос, отрицание) и **казахская речь** в свободном вводе оператора.
5. **Свой корпус** от многих разных людей — главный рычаг точности распознавания.

Подробно, с этапами, метриками и критериями остановки — [ROADMAP.md](ROADMAP.md).
